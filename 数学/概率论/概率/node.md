概率类算法题（尤其是**概率 DP / 期望 DP**）在算法竞赛和面试中有一套非常标准的**思考框架**。

很多同学觉得概率题难，是因为容易陷入“从头到尾正向模拟无限回合”的迷宫里。掌握了以下 **4 步思考框架** 和 **2 个核心思维技巧**，你就能轻松破解绝大多数概率题。

---

### 🧠 概率 DP 核心心法：倒推思维 + 消除自环 (例题：[不公平对局](https://www.nowcoder.com/practice/55cfa1c9f8c146fe81c3d676859b9d4e?channelPut=tracker2))

> **概率求“胜率”，期望求“步数”。**
> - 求胜率：常用 **倒推 DP**（从终局状态推回初始状态）。
> - 求期望：常用 **逆向方程**（从当前状态到终点的期望步数）。

---

### 📋 4 步标准思考框架

#### 第一步：找“终局”与“先后手”（定义胜利/失败条件）
在动笔前，先问自己三个问题：
1. **游戏什么情况下结束？** （比如：某人吃子达到 $x$）。
2. **谁先手？顺序是什么？** （比如：小红先尝试，小红没输小紫才尝试）。
3. **终局的概率值是多少？** （小红输 $\to$ 胜率 0；小红胜 $\to$ 胜率 1）。

#### 第二步：定义“以终为始”的状态（定义 DP）
概率题最舒服的定义方式是**倒推**：
* 设 $dp[\text{当前状态}]$ 表示：**从当前状态出发，最终小红获胜的概率**。
* **目标**：求初始状态 $dp[\text{起点}]$（如 $dp[0][0]$）。
* **已知边界**：终局状态的概率（如 $dp[x][j] = 0, dp[i][x] = 1$）。

#### 第三步：枚举“单步互斥事件”（列全概率公式）
思考：从当前状态出发，**进行一轮操作后，可能发生哪些互斥事件？**
把所有可能的事件列出来，算出它们的**发生概率**以及**转移到的新状态**：

$$\text{当前状态} = \sum (\text{事件 } k \text{ 发生的概率} \times \text{转移到的新状态的胜率})$$

比如上一题：
1. 红吃紫吃：概率 $P_{11}$，转移到 $(i+1, j+1)$
2. 红吃紫不吃：概率 $P_{10}$，转移到 $(i+1, j)$
3. 红不吃紫吃：概率 $P_{01}$，转移到 $(i, j+1)$
4. 啥也没发生：概率 $P_{00}$，维持 $(i, j)$

#### 第四步：消除“自环/无效回合”（移项化简）
如果某一步有概率“啥也没发生”，转移方程就会出现自环：
$$DP_{\text{当前}} = \text{其他有效转移} + P_{00} \cdot DP_{\text{当前}}$$

**处理技巧**：直接移项！
$$(1 - P_{00}) \cdot DP_{\text{当前}} = \text{其他有效转移}$$
$$DP_{\text{当前}} = \frac{\text{其他有效转移}}{1 - P_{00}}$$
> **本质物理意义**：“啥也没发生”的回合对最终谁赢没有任何贡献。我们只需要计算**“在至少发生了一件有效事件的前提下”**，各个有效事件的条件概率。

---

### 💡 2 个让代码极简的思维外挂

#### 外挂 1：条件概率“归一化”思维（不用列复杂方程）
既然“啥也没发生”对结果无影响，你在分析单步事件时，可以**直接忽略“无效事件”**：
1. 算所有有效事件的概率和：$D = P_{\text{有效1}} + P_{\text{有效2}} + \dots$
2. 每个有效事件的**实际权重**就是 $\frac{P_{\text{有效}}}{D}$。
3. 一步到位写出转移：$DP_{\text{当前}} = \sum \left( \frac{P_{\text{有效}}}{D} \times DP_{\text{新状态}} \right)$。

#### 外挂 2：用“垫片/虚拟边界”消除 `if` 分支（就像你刚才发现的）
当边界条件很明确时（比如超过 $x$ 就输）：
* **不要**在 DP 循环里写满 `if (i + 1 < x)`。
* **直接**将 DP 数组开大一圈 `dp[x+1][x+1]`，把 `dp[x][j]` 初始化为 0，把 `dp[i][x]` 初始化为 1。
* 这样循环内部就是一条纯粹的数学算式，既不会越界，又写得飞快。

### 总结口诀

1. **概率倒着推，终点填 0 1；**
2. **单步拆事件，概率乘以胜；**
3. **遇到无效轮，移项除以 D；**
4. **数组开大一，边界不用 if。**
