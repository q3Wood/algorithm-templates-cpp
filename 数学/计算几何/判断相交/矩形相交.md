### 一、 两个“相同尺寸矩形”（$H \times W$）的判定结论

假设我们要找两个不重叠的 **$H \times W$（高 $H$，宽 $W$）** 的矩阵：
若记 $(i, j)$ 为矩形的**右下角坐标**，我们同样统计所有合法矩形右下角的极值 `min_x, max_x, min_y, max_y`。

这两个相同尺寸的矩形不重叠的**充要条件**是：
1. **上下不重叠**：$max\_x - min\_x \ge H$ （行方向差值大于等于高度 $H$）
2. **左右不重叠**：$max\_y - min\_y \ge W$ （列方向差值大于等于宽度 $W$）

**判断代码**：
```cpp
return (max_x - min_x >= H) || (max_y - min_y >= W);
```

**原理推导**：
* 矩形 $1$ 右下角在 $i_1$，占用的行是 $[i_1 - H + 1, \ i_1]$；
* 矩形 $2$ 右下角在 $i_2$，占用的行是 $[i_2 - H + 1, \ i_2]$；
* 两个矩形行方向不重叠 $\iff i_1 < i_2 - H + 1 \iff \mathbf{i_2 - i_1 \ge H}$。
* 只要最靠下和最靠上的右下角行号差值 $max\_x - min\_x \ge H$，它们就必定上下不重叠！

### 二、 如果是“不同尺寸”或“任意矩形”呢？

如果两个矩形**尺寸不相同**（比如一个是 $H_1 \times W_1$，另一个是 $H_2 \times W_2$），或者**尺寸不固定**：

直接用全局极值 `max_x - min_x` **就会失效**。因为不同尺寸矩形的合法位置集合不同，$R_1$ 的 `min_x` 和 $R_2$ 的 `max_x` 并不来自于同一个集合。

对于**不同尺寸/任意矩形**，常用的推广方法是 **“分割线法”**（也称前后缀最值法）：

两个不重叠的矩形，一定可以被**一条水平直线**或**一条垂直直线**隔开。
* **枚举分割行 $R$**：判断行 $[0, R]$ 内是否存在矩形 $A$，且行 $[R+1, m-1]$ 内是否存在矩形 $B$；
* **枚举分割列 $C$**：判断列 $[0, C]$ 内是否存在矩形 $A$，且列 $[C+1, n-1]$ 内是否存在矩形 $B$。

通过预处理**前缀/后缀矩形信息**，可以在 $O(m + n)$ 的时间内判断完任意不同尺寸矩形的不重叠问题。

---

### 总结

1. **同等尺寸（正方形 $k \times k$ 或固定矩形 $H \times W$）**：
   👉 **直接用全局极值判定**（`max_x - min_x >= H || max_y - min_y >= W`），时间复杂度最低（$O(1)$ 判定）。
2. **不同尺寸 / 任意矩形**：
   👉 **使用分割线法（枚举分割行/列 + 前后缀最值）**。

### 一、 同等长度线段（固定长度 $L$）—— 极值判定法
> **对应前文**：对应你在 2D 正方形题里用的 `max_x - min_x >= k`。

假设数轴上有一堆长度为 $L$ 的线段，它们的右端点坐标分别是 $x_1, x_2, \dots, x_n$：

* **核心结论**：这一堆线段中，**是否存在两条互不重叠的线段**？
  $$\text{充要条件：} \mathbf{\max(x) - \min(x) \ge L}$$
* **原理**：只需要看**最左边**那条线段和**最右边**那条线段。如果它们俩都重叠，那么其他任意两条线段也必然重叠。

### 二、 任意两条线段 $[a_1, b_1]$ 和 $[a_2, b_2]$ 的判定
假设数轴上有两条任意长度的线段 $A=[a_1, b_1]$ 和 $B=[a_2, b_2]$（假设 $a \le b$）：

```text
线段 A:  a1 |--------| b1
线段 B:               a2 |--------| b2   (不重叠)
```

#### 1. 不重叠（完全分离）的条件
* **公式**：$\mathbf{b_1 < a_2}$ **或** $\mathbf{b_2 < a_1}$
* **口诀**：*“一个的终点，在另一个的起点左边。”*

#### 2. 重叠（有交集）的条件
直接将上面的不重叠条件**取反**（利用德·摩根定律），得到重叠公式：
* **公式**：$\mathbf{\max(a_1, a_2) \le \min(b_1, b_2)}$
* **交集长度**：$\max(0, \ \min(b_1, b_2) - \max(a_1, a_2))$
* **口诀**：*“较大的起点 $\le$ 较小的终点。”* （这个公式在区间重叠题里极其常用！）

#### 3. 中心点 + 半长判定法（物理 / 游戏引擎最爱）
假设线段 $A$ 中心点为 $c_1$，半长为 $r_1$；线段 $B$ 中心点为 $c_2$，半长为 $r_2$：
* **不重叠条件**：$\mathbf{|c_1 - c_2| \ge r_1 + r_2}$ （中心距离 $\ge$ 两者半径之和）
* **重叠条件**：$\mathbf{|c_1 - c_2| < r_1 + r_2}$

### 三、 从一维（数轴）推广到高维（分离轴定理 SAT）

游戏和算法中最经典的 **AABB (Axis-Aligned Bounding Box) 碰撞检测**，就是完全建立在一维数轴判断上的：

| 维度 | 几何图形 | 不重叠的充要条件 |
| :--- | :--- | :--- |
| **一维 (1D)** | 线段 / 区间 | **X 轴**上不重叠 |
| **二维 (2D)** | 轴对齐矩形 / 正方形 | **X 轴**不重叠 **OR** **Y 轴**不重叠 |
| **三维 (3D)** | 轴对齐长方体 / 立方体 | **X 轴**不重叠 **OR** **Y 轴**不重叠 **OR** **Z 轴**不重叠 |

**核心思想**：高维物体不重叠 $\iff$ **投影到某一个坐标轴上不重叠**！

### 四、 离散网格（格子） vs 连续数轴（注意踩坑点）

在做算法题时，要注意区分**网格格子**和**连续数轴**的微小差异：

| 概念 | 连续数轴（几何） | 离散网格（矩阵格子） |
| :--- | :--- | :--- |
| **区间表示** | $[1, 3]$ 表示长度为 $3 - 1 = 2$ | 占第 $1, 2, 3$ 格，长度/格子数 $= 3 - 1 + 1 = 3$ |
| **不重叠条件** | $b_1 \le a_2$ （端点重合不算重叠） | $b_1 < a_2$ （即 $a_2 - b_1 \ge 1$，不能占同一个格） |
| **固定长度 $L$ 右端点差值** | $x_2 - x_1 \ge L$ | $x_2 - x_1 \ge L$ （右下角坐标差值依然是 $\ge L$） |

### 总结模板记忆清单

1. **判断两条线段是否有交集**：`max(start1, start2) <= min(end1, end2)`
2. **计算两条线段交集长度**：`max(0, min(end1, end2) - max(start1, start2))`
3. **判断同长线段集是否有解**：`max_pos - min_x >= L`
4. **高维不重叠判定**：只要找到**任意一个坐标轴**满足不重叠，整个高维图形就不重叠！
