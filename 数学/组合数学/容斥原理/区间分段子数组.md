它的核心思想是**“正难则反”**：
$$\text{峰值子数组的数量} = \text{区间内的总子数组数量} - \text{非峰值子数组的数量}$$

---

### 第一步：计算区间 $[L, R]$ 内的“总子数组数量”

对于一个长度为 $N_{len} = R - L + 1$ 的区间，它里面包含的所有子数组（无论长短、无论是否包含峰值）的总数量为：
$$\text{总子数组数量} = \frac{N_{len}(N_{len} + 1)}{2} = \frac{N_{len}^2 + N_{len}}{2}$$

---

### 第二步：什么叫“非峰值子数组”？

一个子数组**不是**峰值子数组，意味着它的**内部没有包含任何峰值**。

假设区间 $[L, R]$ 内部有 $m$ 个峰值点，坐标分别为 $p_1, p_2, \dots, p_m$。
这 $m$ 个点把整个大区间 $[L, R]$ 切分成了 $m + 1$ 个重叠的小段：

```text
区间 [L, R] 被峰值点切割示意图：

[ L -------- p1 -------- p2 -------- ... -------- pm -------- R ]
  |--第0段--|  |--第1段--|                        |--第m段--|
```

* **第 $0$ 段**：$[L, p_1]$，长度 $len_0 = p_1 - L + 1$
* **第 $1$ 段**：$[p_1, p_2]$，长度 $len_1 = p_2 - p_1 + 1$
* $\dots$
* **第 $r$ 段**：$[p_r, p_{r+1}]$，长度 $len_r = p_{r+1} - p_r + 1$
* $\dots$
* **第 $m$ 段**：$[p_m, R]$，长度 $len_m = R - p_m + 1$

**关键结论**：任何一个“非峰值子数组”，都**必须完整地包裹在某一个单独的小段** $[p_r, p_{r+1}]$ 内部。

---

### 第三步：容斥原理求“非峰值子数组总数”

我们分别计算每个小段内部的子数组数量并相加：
* 第 $r$ 段（长度为 $len_r$）内部的子数组数量为 $\frac{len_r(len_r + 1)}{2}$。
* 所有小段的子数组加起来：$\sum_{r=0}^m \frac{len_r(len_r + 1)}{2}$。

**但是，这里有重复计算（容斥原理）！**
相邻的两个小段（比如第 $0$ 段 $[L, p_1]$ 和第 $1$ 段 $[p_1, p_2]$）在端点 $p_1$ 处重叠了。
长度为 1 的单元素子数组 $[p_1, p_1]$ 被第 0 段算了一次，又被第 1 段算了一次。
共有 $m$ 个这样的分割点（$p_1, p_2, \dots, p_m$），所以**有 $m$ 个长度为 1 的单元素子数组被重复算了 2 次**。

必须减去这重复计算的 $m$ 次：
$$\text{非峰值子数组总数} = \sum_{r=0}^m \frac{len_r(len_r + 1)}{2} - m$$

---

### 第四步：代数化简（导出图片中的公式）

我们对上面算出的“非峰值子数组总数”做代数展开：

1. 先展开分子：
   $$\sum_{r=0}^m \frac{len_r(len_r + 1)}{2} = \frac{1}{2} \sum_{r=0}^m len_r^2 + \frac{1}{2} \sum_{r=0}^m len_r$$

2. 巧妙求和 $\sum_{r=0}^m len_r$（所有段的长度相加）：
   $$\sum_{r=0}^m len_r = (p_1 - L + 1) + (p_2 - p_1 + 1) + \dots + (R - p_m + 1)$$
   注意看，$p_1, p_2, \dots, p_m$ 在加减中**全都相互抵消掉了**（错位相消）！
   最后只剩下：
   $$\sum_{r=0}^m len_r = (R - L) + \underbrace{(1 + 1 + \dots + 1)}_{m+1 \text{ 个 1}} = (R - L + 1) + m = N_{len} + m$$

3. 代回非峰值子数组公式：
   $$\text{非峰值子数组总数} = \frac{1}{2} \sum_{r=0}^m len_r^2 + \frac{N_{len} + m}{2} - m = \frac{1}{2} \sum_{r=0}^m len_r^2 + \frac{N_{len} - m}{2}$$

4. **最后用总数减去非峰值数量（正难则反）**：
   $$\text{Ans} = \text{总子数组数量} - \text{非峰值子数组总数}$$
   $$\text{Ans} = \frac{N_{len}^2 + N_{len}}{2} - \left( \frac{1}{2} \sum_{r=0}^m len_r^2 + \frac{N_{len} - m}{2} \right)$$
   分母通分，全部合并到分子上：
   $$\text{Ans} = \frac{(N_{len}^2 + N_{len}) - (N_{len} - m) - \sum_{r=0}^m len_r^2}{2}$$
   $N_{len}$ 相互抵消：
   $$\mathbf{\text{Ans} = \frac{N_{len}^2 + m - \sum_{r=0}^m len_r^2}{2}}$$

**这就完美导出了图片中的公式！**

---

### 总结公式中的每一个变量含义

* $N_{len} = R - L + 1$：区间 $[L, R]$ 的总长度。
* $m$：区间内部的峰值点个数。
* $len_0 = p_1 - L + 1$：左边界到第一个峰值点的长度。
* $len_m = R - p_m + 1$：最后一个峰值点到右边界的长度。
* $len_r = p_{r+1} - p_r + 1$ （$1 \le r \le m-1$）：相邻两个峰值点之间的长度。
