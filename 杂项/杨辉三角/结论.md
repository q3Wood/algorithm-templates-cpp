### 一、 杨辉三角（二项式系数）常用性质大盘点

杨辉三角在算法竞赛中极其高频，以下整理了最核心的**五大类必备性质**：

#### 1. 基础递推与对称性
* **对称性**：
  $$\binom{n}{m} = \binom{n}{n-m}$$
* **加法递推式（杨辉三角构造核心）**：
  $$\binom{n}{m} = \binom{n-1}{m-1} + \binom{n-1}{m}$$

#### 2. 行求和性质
* **整行求和**：
  $$\sum_{i=0}^n \binom{n}{i} = 2^n$$
* **奇偶项和相等**：
  $$\binom{n}{0} + \binom{n}{2} + \binom{n}{4} + \dots = \binom{n}{1} + \binom{n}{3} + \binom{n}{5} + \dots = 2^{n-1}$$
  （即带符号和 $\sum_{i=0}^n (-1)^i \binom{n}{i} = (1-1)^n = 0$）
* **平方和（范德蒙德卷积特例）**：
  $$\sum_{i=0}^n \binom{n}{i}^2 = \binom{2n}{n}$$

#### 3. 斜向求和（曲棍球棒恒等式 / 朱世杰恒等式）
杨辉三角沿着某条对角线求和，拐个弯等于下一个位置的数：
$$\sum_{i=r}^n \binom{i}{r} = \binom{n+1}{r+1}$$
* *例*：$\binom{2}{2} + \binom{3}{2} + \binom{4}{2} = \binom{5}{3}$
* 这个公式常用于求自然数幂和，比如 $1 + 2 + \dots + n = \sum \binom{i}{1} = \binom{n+1}{2} = \frac{n(n+1)}{2}$。

#### 4. 卷积恒等式（范德蒙德卷积 Vandermonde's Identity）
从大小为 $n$ 和 $m$ 的两个集合中一共选 $k$ 个元素：
$$\sum_{i=0}^k \binom{n}{i} \binom{m}{k-i} = \binom{n+m}{k}$$
算法题中如果看到两个组合数相乘且下标之和为定值（$i + (k-i) = k$），立刻套用此公式化简。

#### 5. 数论与模意义性质
* **卢卡斯定理（Lucas Theorem）**（模数 $p$ 为质数）：
  $$\binom{n}{m} \equiv \binom{\lfloor n/p \rfloor}{\lfloor m/p \rfloor} \binom{n \bmod p}{m \bmod p} \pmod p$$
  用于处理 $n, m \le 10^{18}$ 但质模数 $p \le 10^5$ 的情况。
* **库默尔定理（Kummer's Theorem）**：
  组合数 $\binom{n}{m}$ 中质因子 $p$ 的最高次幂，等于在 $p$ 进制下计算 $m + (n-m)$ 时产生的**进位次数**。
  （特别推论：当 $p=2$ 时，$\binom{n}{m}$ 为奇数当且仅当 $m \text{ AND } (n-m) = 0$，即 $m$ 在二进制下是 $n$ 的子集 `(m & n) == m`）。
