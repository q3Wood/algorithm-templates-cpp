### 一、解题思路

#### 1. 确定排序规则
题目要求：
1. 第一优先级：**数位和**（各位数字相加）按**升序**排序。
2. 第二优先级：若数位和相同，按**数字本身的大小**升序排序。

因为数组中的数字**互不相同**，所以排序后的目标数组每个位置放置的元素是**唯一确定**的。

#### 2. 置换环（Cycle Decomposition）求最小交换次数
将原数组通过两两交换调整为目标排序，是经典的**置换环**问题：
- 指向规则：【当前位置】→【这个数字最终应该去的位置】
- 任意一个置换都可以分解为若干个互不相交的**环（Cycle）**。
- 如果一个环的长度为 $k$（即有 $k$ 个元素需要轮换位置），要让这 $k$ 个元素全部归位，所需的最小交换次数正好是 **$k - 1$** 次。
- 假设数组长度为 $n$，分解出的环的总数为 $C$（包括长度为 1 的自环，即原本就在正确位置上的元素），则总的最小交换次数为：
  $$\sum (k_i - 1) = \sum k_i - \sum 1 = n - C$$
  即：**最小交换次数 = 元素总数 $n$ - 环的数量 $C$**。

---

### 二、具体步骤

1. 记录每个元素的 `(数位和, 数值本身, 原始下标 i)`。
2. 按照自定义规则进行排序。
3. 排序后，目标位置 `j` 上的元素原本来自于原始下标 `orig_idx`，这就构成了一条有向边 `j -> orig_idx`。
4. 使用一个布尔数组 `visited` 遍历找环，统计环的数量 $C$。
5. 最终答案返回 $n - C$。

---

### 三、代码实现
#### C++

```cpp
#include <vector>
#include <numeric>
#include <algorithm>

using namespace std;

class Solution {
public:
    int minSwaps(vector<int>& nums) {
        int n = nums.size();

        auto get_digit_sum = [](int x) {
            int s = 0;
            while (x > 0) {
                s += x % 10;
                x /= 10;
            }
            return s;
        };

        struct Node {
            int d_sum;
            int val;
            int orig_idx;
        };

        vector<Node> arr(n);
        for (int i = 0; i < n; ++i) {
            arr[i] = {get_digit_sum(nums[i]), nums[i], i};
        }

        // 自定义排序：先看数位和，再看数值本身
        sort(arr.begin(), arr.end(), [](const Node& a, const Node& b) {
            if (a.d_sum != b.d_sum) return a.d_sum < b.d_sum;
            return a.val < b.val;
        });

        // 统计置换环数量
        vector<bool> visited(n, false);
        int cycles = 0;

        for (int i = 0; i < n; ++i) {
            if (visited[i]) continue;

            cycles++;
            int curr = i;
            while (!visited[curr]) {
                visited[curr] = true;
                curr = arr[curr].orig_idx;
            }
        }

        return n - cycles;
    }
};
```

### 四、复杂度分析

- **时间复杂度**：
  - 计算数位和：$O(n \log_{10} M)$，其中 $M$ 为数字最大值，常数很小。
  - 排序：$O(n \log n)$。
  - 遍历找环：每个节点只会被访问一次，时间为 $O(n)$。
  - **总时间复杂度**：$O(n \log n)$。
- **空间复杂度**：
  - 需要存储辅助数组和访问标记，空间复杂度为 $O(n)$。

### 五、并查集解
```cpp
#include <vector>
#include <numeric>
#include <algorithm>

using namespace std;

class Solution {
    // 标准并查集模板
    struct DSU {
        vector<int> parent;
        DSU(int n) : parent(n) {
            iota(parent.begin(), parent.end(), 0);
        }
        int find(int x) {
            return parent[x] == x ? x : parent[x] = find(parent[x]);
        }
        // 若两个节点不在同一集合中，合并并返回 true；否则返回 false
        bool unite(int x, int y) {
            int rootX = find(x);
            int rootY = find(y);
            if (rootX != rootY) {
                parent[rootX] = rootY;
                return true; // 成功合并，相当于消除了一次置换偏差
            }
            return false;
        }
    };

public:
    int minSwaps(vector<int>& nums) {
        int n = nums.size();

        auto get_digit_sum = [](int x) {
            int s = 0;
            while (x > 0) {
                s += x % 10;
                x /= 10;
            }
            return s;
        };

        // 记录：(数位和, 数值, 原始下标)
        struct Node {
            int d_sum;
            int val;
            int orig_idx;
        };
        vector<Node> arr(n);
        for (int i = 0; i < n; ++i) {
            arr[i] = {get_digit_sum(nums[i]), nums[i], i};
        }

        // 排序得到目标位置
        sort(arr.begin(), arr.end(), [](const Node& a, const Node& b) {
            if (a.d_sum != b.d_sum) return a.d_sum < b.d_sum;
            return a.val < b.val;
        });

        DSU dsu(n);
        int swaps = 0;

        // 目标位置 i 与其原本的原始下标 arr[i].orig_idx 进行连边
        for (int i = 0; i < n; ++i) {
            // 每成功合并两个不在同一环内的位置，所需交换次数 +1
            if (dsu.unite(i, arr[i].orig_idx)) {
                swaps++;
            }
        }

        return swaps;
    }
};
```
